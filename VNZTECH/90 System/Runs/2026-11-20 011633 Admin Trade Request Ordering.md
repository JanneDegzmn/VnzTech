# Admin Trade Requests Pending-First Ordering

## Request and approval

The owner reported a new notification/trade request appearing below older rows and being rejected accidentally. Source inspection found the admin page sorted solely by `requested_at DESC, id DESC`, so a newer processed request could be above an older pending one. No screenshot personal data was transcribed.

The owner selected `approve_pending_first` for Plan v1 in this conversation. The approved change is limited to the admin Trade Requests list: PENDING first, newest within pending; APPROVED next; all other statuses afterward, newest within that group.
