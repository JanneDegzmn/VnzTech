# {{title}}

## Goal and acceptance criteria

## Request, source, and approved scope

Record proposal version, affected paths/actions, checks, documentation, risks/recovery, and exclusions. Record actual owner approval words/source only when given; recording time is not an invented message timestamp.

## Ownership and handoff

Writer/runner, assigned roles, file ownership, previous writer/handoff, actual branch/Git state. Markers are advisory, not locks.

## Progress and checkpoint

Last completed step, next safe action, blockers, and Asia/Manila timestamp. Save after milestones and before stop/handoff/final.

## Changed files and checks

Attributable paths only. Actual commands/results, failures, side effects, configuration applied or unrun, and limits.

## Completion and acceptance

Implementation state, verification evidence, owner acceptance, and unresolved issues. Never infer acceptance from implementation approval.
