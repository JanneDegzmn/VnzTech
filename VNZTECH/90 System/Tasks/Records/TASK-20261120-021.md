# Seller Security action sizing and icon v1.0

## Request and read-only diagnosis

Owner request: “Tignan mo yung UI ng module nato sa seller side. paki ayos nga tingnan mo yung mga button anlalaki jusko tapos yung icon ng module pakipalitan ng gray.”

The provided screenshot shows the Seller Security page. Read-only inspection found the Security page reuses `.profile-save-button`, whose shared seller style has a 42px minimum height and 17px horizontal padding. Its Save Login Preference action is additionally fixed at 190px wide and 46px high. The sidebar Security icon is a colored lock emoji (`&#128274;`), unlike adjacent text glyphs. `seller_account.css` loads after Seller dashboard/theme styles and is the narrowest place for page-specific overrides.

The repository already has unrelated dirty and untracked changes, including `account/pages/security.php`, `assets/css/seller_account.css`, and the Seller account browser fixture/test. These are pre-existing and will be preserved. No application source or tests have been edited for this request; no tests have been run.

Preserve the current button heights, small-screen full-width behavior, labels, active theme colors, forms, and all password/2FA behavior. Profile and Settings button sizing stays unchanged.
- Render only the Security sidebar lock as grayscale in both Seller themes and active/inactive states; do not restyle other module icons.
- Add focused coverage to the existing Seller account UX browser test for button sizing, responsive overflow/layout, and the grayscale icon across light/dark and mobile/desktop widths. Run the existing focused account UI regression and relevant PHP/Node syntax checks; inspect representative previews.
- No backend, authentication, 2FA, API, database, or Admin/Public changes.
