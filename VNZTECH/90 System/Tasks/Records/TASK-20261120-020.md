# Admin transaction modal layering v1.0

## Request and read-only diagnosis

Owner reported that the transaction “View” modal dims the content but leaves the Admin sidebar/topbar bright, and the topbar overlaps the modal. Owner requested an immediate, accurate, safe fix.

Source inspection found `.admin-transaction-modal` at `z-index: 9999` in `assets/css/admin_transactions.css`, below the Admin topbar at `11010` and sidebar at `11030` in `assets/css/admin_topbar.css`. The existing Admin submission modal already receives a shell-specific `11035` layer in that same topbar stylesheet. The transaction modal is inserted in `#contentArea`; its fixed inset backdrop should cover the viewport once its Admin layer is raised above the shell.

The owner approved v1.0 via the structured response `approve_v1_0=true` in this conversation. No application edits had been made at approval.

## Proposed scope v1.0

- Give only the Admin transaction details modal the existing `11035` shell layer, matching the Admin submission modal, so its backdrop covers the topbar/sidebar and its panel paints above them.
- Add a focused browser regression using the production Admin shell/modal CSS to verify viewport-wide backdrop coverage and correct stacking at mobile and desktop widths in light and dark themes.
- Preserve modal content, transaction loading/data, permissions, close behavior, and all Seller/Public UI. Do not modify the global topbar/sidebar layers.

## Implementation and verification

- `assets/css/admin_topbar.css`: added an Admin-shell-only `z-index: 11035` override for `.admin-transaction-modal`, matching the existing Admin submission modal. The transaction modal's own full-viewport fixed backdrop and close behavior remain unchanged.
- Added `tests/admin_transactions_modal_browser_test.mjs`, which loads the production Admin shell and modal styles. It checks full-viewport modal/backdrop geometry, paint order/hit-testing above the topbar and desktop sidebar, light/dark panel theme, responsive overflow, and close state.
- PASS: **81** browser assertions across light/dark at 375/768/1440px.
- PASS: `node --check tests/admin_transactions_modal_browser_test.mjs`. No PHP source changed.
- Inspected synthetic previews at light 375px, light 1440px, and dark 1440px. The topbar/sidebar are dimmed and the modal is visibly on top.
- Limits: isolated browser fixture with production CSS, not a live Admin account/transaction API. No physical-device, screen-reader, or deployment check.
